# lakhanadewar.github.io

Personal portfolio of **Lakhan Adewar**, QA automation engineer in London. Live at https://lakhanadewar.github.io/

Built on the [mj-folio](https://github.com/ursmaheshj/mj-folio) template: plain HTML, CSS and JavaScript with no build step.

## Editing content

All page content lives in [`js/content.js`](js/content.js): profile, CV, skills, experience, projects, blog posts, certificates and contact details. Edit it, push to `main`, and GitHub Pages publishes the change.

- Profile photo: `images/profile.jpg`
- Certificate badges: `images/certificates/`
- Articles hosted on this site: `posts/`

The previous version of the site is kept on the `old-portfolio` branch.
